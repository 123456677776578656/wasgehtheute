2. Globaler Seitenaufruf-Zähler

Für die öffentliche Anzeige der Gesamtzahl der Seitenaufrufe wird CounterAPI verwendet. Beim Öffnen der Startseite ruft der Browser einen öffentlichen API-Endpunkt von CounterAPI auf und erhöht den Zähler um eins. Dadurch kann CounterAPI technisch notwendige Verbindungsdaten wie die IP-Adresse erhalten. Der angezeigte Wert ist ein Seitenaufruf-Zähler und keine verlässliche Zahl eindeutiger Personen.

Es werden von WasGehtHeute.ch hierfür keine Cookies gesetzt und kein eigenes Nutzerprofil erstellt. Der öffentliche CounterAPI-V1-Zähler benötigt keine Anmeldung oder persönliche Kennung.

3. PWA / Offline-Speicher

Die Website kann als Progressive Web App installiert werden. Ein Service Worker kann dafür statische Dateien wie HTML, CSS, JavaScript und Eventdaten im Browser-Cache speichern, damit die Seite schneller lädt und teilweise offline funktioniert. Diese Daten bleiben lokal auf dem jeweiligen Gerät und können über die Browser- bzw. App-Einstellungen gelöscht werden.

4. Event- und Werbeformular
