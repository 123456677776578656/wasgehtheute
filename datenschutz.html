1. Hosting über GitHub Pages

2. Anfrageverwaltung über Supabase

Wenn du einen Event meldest oder eine Werbeanfrage sendest, werden die von dir eingegebenen Angaben in einer Supabase-Datenbank gespeichert. Je nach Anfrage gehören dazu insbesondere Name bzw. Veranstalter, Firma, E-Mail-Adresse, Eventname, Ort, Venue, Datum, Uhrzeit, Kategorie, Beschreibung, offizielle Webseite, Ticketlink, gewünschter Werbeplatz, gewünschter Zeitraum und deine Nachricht.

Die Daten werden ausschließlich verwendet, um die Anfrage zu prüfen, Rückfragen zu ermöglichen, den Bearbeitungsstatus zu verwalten und – bei akzeptierten Eventanfragen – eine mögliche Veröffentlichung manuell vorzubereiten. Eine Eventanfrage wird niemals allein durch das Absenden automatisch öffentlich veröffentlicht.

Die Datensätze erhalten einen internen Bearbeitungsstatus und können eine interne Admin-Notiz enthalten. Diese Verwaltungsdaten sind für normale Besucher nicht lesbar. Der Zugriff auf eingegangene Anfragen ist technisch durch Supabase Auth und Row Level Security beschränkt.

Die Angaben werden grundsätzlich so lange gespeichert, wie sie für die Bearbeitung, Nachvollziehbarkeit und erforderliche Rückfragen benötigt werden. Erledigte oder abgelehnte Anfragen sollen regelmäßig geprüft und gelöscht werden, sobald keine sachliche oder gesetzliche Aufbewahrungsnotwendigkeit mehr besteht. Als betriebliche Richtlinie ist eine regelmäßige Löschprüfung spätestens nach 12 Monaten vorgesehen.

3. Zähler über CounterAPI

WasGehtHeute.ch verwendet CounterAPI für einfache Aufruf- und Klickzähler. Der Browser ruft dafür CounterAPI-Endpunkte auf. Die angezeigten Zahlen sind technische Trends und keine verlässliche Zahl eindeutig identifizierter Personen.

WasGehtHeute.ch erstellt damit kein eigenes personenbezogenes Nutzerprofil.

4. Lokaler Speicher im Browser

Favoriten und technische Einstellungen können im lokalen Browserspeicher gespeichert werden. Diese Daten bleiben grundsätzlich auf dem verwendeten Gerät und können über die Browser- oder App-Einstellungen gelöscht werden.

5. PWA / Offline-Cache

Die Website kann als Progressive Web App installiert werden. Ein Service Worker speichert statische Dateien wie HTML, CSS, JavaScript und Eventdaten im Browser-Cache, damit die Seite schneller lädt und teilweise offline funktioniert. Der Cache kann über die Browser- bzw. App-Einstellungen gelöscht werden.

6. Karte und Standort

Die Karte wird erst geladen, wenn der Nutzer sie aktiv anfordert. Dafür werden Leaflet und Kartendaten von OpenStreetMap geladen. Bei solchen externen Abrufen können die jeweiligen Anbieter technisch notwendige Verbindungsdaten erhalten.

Die Funktion «Nähe» fragt – nur nach einer Browserfreigabe – den Gerätestandort ab, um Events nach Entfernung zu sortieren. WasGehtHeute.ch sendet diese Standortkoordinaten nicht an die Anfrage-Datenbank.

7. Externe Links

Eventkarten und Detailseiten enthalten Links zu Veranstaltern, Gemeinden, Ticketanbietern, Tourismusstellen und weiteren externen Quellen. Sobald ein solcher Link geöffnet wird, gelten die Datenschutzbestimmungen der jeweiligen externen Website.

8. Keine personalisierte Werbung

Im aktuellen Stand setzt WasGehtHeute.ch keine Dienste wie Google Analytics oder Meta Pixel ein. Falls später weitere Analyse- oder Werbedienste ergänzt werden, wird diese Datenschutzerklärung entsprechend aktualisiert.

9. Rechte betroffener Personen

Nach dem anwendbaren schweizerischen Datenschutzrecht können betroffene Personen insbesondere Auskunft über die Bearbeitung ihrer Personendaten verlangen und – soweit die gesetzlichen Voraussetzungen erfüllt sind – Berichtigung oder Löschung verlangen. Sobald eine Betreiber-Kontaktadresse hinterlegt ist, können entsprechende Anfragen dorthin gerichtet werden.
